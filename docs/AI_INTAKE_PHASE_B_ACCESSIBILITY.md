# AI Intake Phase B Accessibility

Doctor page uses one H1, ordered section headings, semantic `dl`/`ol`, keyboard-native links, visible focus from shared controls, `role=alert` for emergency/error, `role=note` for AI disclaimer, text plus color for evidence/emergency meaning, wrapping for long patient text, responsive single-column fallback, and locale-driven RTL.

Acceptance target: keyboard-only flow, 200% zoom/reflow, EN/AR/CKB direction, screen-reader headings/landmarks, emergency announcement, meaningful link names, and automated axe scan with zero serious/critical issues.
